# Unslop direction — M8 immersion pages

New routes: `/immersion`, `/reading`, `/listening`, `/speaking`. Existing shell design language is
unchanged (one tinted neutral ramp, one blue accent, 16px lucide icons, 4px spacing scale).

## Audit

No slop found in the existing shell or in the M7 screens that set the pattern. The risk in M8 is
visualising token states: a temptation to use bright multi-colour highlights, glowing pills and
badges. The direction below deliberately avoids that.

## Direction

- **Product.** Kotoba turns Japanese text a learner encounters into offline study material.
- **Character.** calm, exact, paper-like — an annotated page, not a dashboard.
- **World.** A desk with a paper dictionary and a pencil: hairline rules, quiet margin notes.
- **Moments.** One per screen: the tokenized Japanese line where status is shown by a thin underline
  (accent for known, muted for learning, dotted for unknown), and the passage line with kana above
  the Japanese. No generated images.
- **Signature.** The same small status key (known / learning / unseen / unknown) appears once on
  each text surface and nowhere else.

All spacing on the existing 4px scale; no new colours, no emoji, no glows, no animated layout.
